# 🎓 Student Registration System

A full-stack web application built for [Insert Class Name] assignment.

## 🛠️ Technologies Used
- **Frontend:** React, Tailwind CSS, Vite (HTML/JS/CSS)
- **Backend:** Node.js, Express.js
- **Database:** MySQL

## ✨ Features
- Fully responsive design (Mobile, Tablet, Desktop)
- Glassmorphism UI theme (Lilac, White, Black)
- Create, Read, Update, and Delete (CRUD) operations
- Live search filtering
- Form validation (prevents duplicate emails)

## 🚀 How to Run Locally
1. Clone the repository.
2. Set up the MySQL database by running `database.sql` in MySQL Workbench.
3. In the `backend` folder:
   - Run `npm install`
   - Create a `.env` file with your MySQL credentials
   - Run `node server.js`
4. In the `frontend` folder:
   - Run `npm install`
   - Run `npm run dev`
5. Open the localhost link provided by Vite.
